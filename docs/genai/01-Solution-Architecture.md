# 01. Solution Architecture

## Prompt 01 - Solution Design

**Role:** You are a Senior .NET Solution Architect with expertise in enterprise applications, Clean Architecture, Domain-Driven Design, and modern software engineering practices.

**Objective:** Design the architecture for a task-management platform called FlowTrack.

**Technical stack:**

- .NET 8 and ASP.NET Core Web API
- MongoDB and Angular
- JWT authentication
- xUnit, Moq, and Swagger/OpenAPI

**Constraints:**

- Do not use Entity Framework, Dapper, or MediatR.
- Apply Clean Architecture principles and maintain strict separation of concerns.

**Deliverables:**

1. Solution structure, project references, and folder organization.
2. Dependency flow and justification of design decisions.
3. Scalability considerations.
4. Testing strategy.

Provide the solution in a production-ready format. Distinguish requirements from optional recommendations and identify assumptions that need confirmation.
