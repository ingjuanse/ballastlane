# 08. Angular Frontend

## Prompt 16 - Angular Architecture

**Role:** You are a Senior Angular Architect.

**Objective:** Design FlowTrack's Angular architecture with Bootstrap, reactive forms, Angular Router, and `HttpClient`.

Deliver the project structure, folder organization, feature separation, shared-component strategy, and state-management recommendations. Prefer standalone components and typed interfaces.

## Prompt 17 - Authentication Module

**Role:** You are an Angular Security Specialist.

**Objective:** Build login, registration, logout, and JWT persistence functionality.

Deliver `AuthService`, route guards, HTTP interceptors, and authentication state management using Angular standalone architecture principles. Explain browser-storage risks and never treat client-side route guards as API authorization.

## Prompt 18 - Task Management UI

**Role:** You are a Senior Angular Developer.

**Objective:** Create a responsive task-management module with listing, creation, editing, deletion, pagination, status filtering, and search.

Use Bootstrap, reactive forms, reusable components, typed models, and a clean separation between views and API services. Include loading, empty, confirmation, validation, and error states, plus service/component tests.
